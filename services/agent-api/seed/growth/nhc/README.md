# NHC WS/T 423-2022 SD tables

CSV tables digitized from **WS/T 423—2022《7岁以下儿童生长标准》** (NHC, 2022), aligned with the public [groowooth](https://github.com/xiaot945/groowooth) `data/csv/nhc/` export.

Loaded by `agent_api.tools.growth.nhc` using nearest-age row selection and piecewise linear SD interpolation.
